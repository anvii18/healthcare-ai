# 🏥 Healthcare Chatbot UI Design

A modern and responsive Healthcare AI Chatbot frontend built using React and Vite.


## ✨ Features

- Modern Healthcare Chat Interface
- Responsive UI Design
- Component-Based Architecture
- Fast Development with Vite
- Clean and Minimal Design
- Reusable UI Components

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

---

## 📂 Project Structure

```bash
src/
 ├── components/
 ├── pages/
 ├── assets/
 ├── styles/
 └── App.tsx
```

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/palak700/healthcare-ai.git
```

Move into the project folder:

```bash
cd healthcare-ai
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
